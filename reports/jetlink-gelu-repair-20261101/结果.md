# Light Speed 在骁龙 8 Gen 2 上的精度修复记录

2026-11-01，Moto X40，原始 Light Speed 模型不变，测试程序在手机上运行。

已做出通过仓库原有数值对照标准的测试版。验证包含原来的 16 帧序列，以及另一组独立种子的 160 帧合成序列，后者跨过 128 帧完整历史队列。所有帧、输出头和各列均通过，比较阈值没有放宽。这是数值一致性验证，不是真实道路识别准确率评估。

## 找到的问题及修复

逐算子使用完全相同的输入对照后，GELU 的本地误差明显突出；样本中还出现了正输入对应输出大于输入的超调。单独替换该算子，实际模型计算块的平均误差从 0.014174 降至 0.000478。

模型视觉部分有 36 个精确 erf GELU，后半部分有 27 个 tanh 近似 GELU。当前 ORT QNN 构建路径没有保留两种公式的选择。修复分别保留原模型的两种定义，用完整 FP16 位模式查表计算，没有重新训练、拟合输出或更改权重。两种实现各自遍历了全部 63,488 个有限 FP16 输入，均与独立数学参照逐位一致。

当前执行图是 45 个 NPU 计算段和 63 个 CPU 激活节点。Jetlink APK 尚未集成这项修复；这是独立手机测试程序中的实现。

## 已完成的结果

| 验证 | 结果 |
| --- | --- |
| 原 16 帧递推对照 | 全部通过原标准 |
| 独立种子 160 帧递推对照 | 全部通过原标准 |
| 160 帧执行时间 | 平均 73.761 ms，P99 77.256 ms |
| 约一分钟连续压力测试 | 800 帧，平均 73.751 ms，P99 76.631 ms |
| 压力测试实际循环帧率 | 13.335 帧/秒，包含输入和输出文件处理 |
| 压力测试电池温度 | 22 -> 23°C |
| 压力测试 GPU 温度节点 | 31.9 -> 71.8°C，最高 72.2°C |
| 压力测试非有限输出 | 每帧检查，800 帧均未出现 |

压力测试将同一组 160 帧循环五次，状态持续递推、不在循环边界重置。800 帧的有限值检查与 160 帧的完整精度对照是两种不同验证。GPU 温度节点不是 NPU 内核结温，也不表示 GPU 参与了这一版模型计算。测试未修改系统温控或频率。

## 30 ms 还剩什么

30 ms 尚未达到。带执行记录的测试中，CPU 激活约 16.4 ms，NPU 各段合计约 58.9 ms；后者包括主机调用、传输和 RPC，不能解释为纯 NPU 计算耗时。记录本身也有开销。

有依据的下一方向是将已校验的精确激活实现移入 NPU 的自定义算子，保留原公式并减少处理器切换。当前尚未编译或验证该 DSP 实现，不能承诺它已能达到 30 ms。现有结果提供了可复用的数学参照、完整有限输入检查和整模型对照门槛。
